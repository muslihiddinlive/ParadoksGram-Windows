Mini-appni bitta HTML qilib klonlash

Yangi:
- Dev tools → Nusxa: "Bitta HTML qilib saqlash" tugmasi. CSS, skriptlar, rasmlar, shriftlar va videolar bitta .html fayl ichiga joylanadi, fayl internetsiz ochiladi va Saved Messages ga yuboriladi.
- Katta fayllar (video va boshqalar) xotiraga to'lmasdan to'g'ridan-to'g'ri diskka yuklanadi, umumiy chegara 1.5 GB.
- CSS ichidagi 8 MB dan katta fayllar asl manzilida qoladi.
